## 一句话产品定位

> 不做“报数机器”，做“懂你、替你处理”的家庭水质健康管家 —— 把水质数据翻译成**健康影响 + 个性化方案 + 设备联动**，形成“监测—分析—预警—处理”闭环。

## 关键差异化

1. **看得见**：双形态监测终端（便携款 + 旗舰家用款）
2. **看得懂**：三档阈值判定引擎 + 健康画像→个性化方案引擎
3. **做得了**：分级预警 + 净水/软水设备自动联动
4. **诚实边界**：软件已交付（2 软著），硬件与机器学习模型为规划中

## 版本状态

- **V1（已完成）**：两套可运行软件 + 本作品集文档
- **V2（规划中）**：接入真实数据 + 硬件原型 + 小规模试用
- **V3（规划中）**：LLM+RAG 健康咨询 + 生态联动 + 商业化
