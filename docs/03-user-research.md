> 本文件遵循「双源调研」原则：**二手行业数据**（权威机构、标注来源与年份）+ **一手问卷/访谈**（当前为占位示例，待真实投放后替换）。二者交叉验证，避免「凭感觉做产品」。

> 📌 **解读**：净水器「购买」渗透率 23% 意味着大量家庭**还没装**；而即便装了，也普遍缺少「出水是否达标、滤芯何时换」的反馈——这正好是本产品「监测 + 反馈」的空白区。

### 2.2 政策与标准（监管在收紧，利好「可信监测」）

- 2025 年新国标《生活饮用水卫生标准》在既有 106 项基础上新增/收紧多项**特征污染物**指标，家庭端对「达标证明」的诉求上升。
- 「健康中国」与绿色家电/以旧换新政策持续拉动净水与水质健康相关消费。

### 2.3 技术与前沿（2024–2026 趋势，注入时代性）

| 方向 | 关键进展 | 对本产品的意义 |
|---|---|---|
| 微型多参数水质传感 | 多参数集成、功耗与成本下降 | 双形态硬件（入户 + 便携）可行性提升 |
| 生成式 AI / LLM 健康咨询 | 2025 年 LLM 个性化健康建议进入**临床验证**阶段（EHR 集成的患者教育 Agent、多智能体 RAG 生活方式教练等） | 「水质 → 健康建议」可从规则引擎升级为 LLM+RAG（科研路线 B） |
| AI Agent / 智能家居生态 | 家庭设备互联互通、场景化联动成熟 | 与净水/软水设备的「自动处理」闭环更顺 |
| 数据隐私合规 | 健康数据属敏感个人信息，监管趋严 | 「本地优先 + 加密」是卖点也是合规底线 |

> 具体论文出处与论证见 `07-ai-collaboration.md` 与 `10-llm-poc/`（规划）。

## 3. 一手调研（占位示例，待真实问卷替换）

> ⚠️ 以下为**问卷/访谈的结构设计与占位结果**，用于说明方法论与结论推导方式。真实投放后，数字会替换为实际样本数据。

### 3.1 调研设计

- **对象**：目标用户分层抽样（自住房家庭 / 租房宿舍 / 母婴家庭 / 差旅），样本目标 N≈100（问卷）+ 8（深度访谈）。
- **方法**：线上问卷（定量）+ 半结构化访谈（定性）。
- **核心问题**：
  1. 你是否了解家里自来水的水质？（了解程度 1–5）
  2. 是否拥有 TDS 笔/净水器/软水机？（设备拥有率）
  3. 最近一次因水质产生困扰是什么？（开放式）
  4. 若有一款「告诉你水质 + 对健康影响 + 怎么办」的产品，付费意愿？（价格区间）
  5. 对「个人健康数据隐私」的担忧程度？（1–5）

### 3.2 占位结果（示意，待替换）

| 假设 | 占位数据 | 待验证结论 |
|---|---|---|
| 「看不见」真实存在 | 约 **78%** 表示「不了解/说不清家里水质」 | 水质可感知是强需求 |
| 现有工具太简陋 | 拥有 TDS 笔者中 **61%** 表示「只看一个数字、不知道意义」 | 「翻译层」是差异化空白 |
| 「怎么办」是断点 | 遇到水垢/异味时 **54%** 不知道换滤芯还是装软水 | 决策支持是刚需 |
| 付费意愿 | **32%** 愿意为「监测 + 健康建议 + 联动」一次性付费/订阅 | 商业可行性初步成立 |
| 隐私敏感 | **67%** 担忧健康数据被第三方获取 | 「本地优先 + 加密」必须打 |

### 3.3 交叉验证结论（二手 ↔ 一手）

- 二手数据说明**市场有空间**（渗透率 23%）、一手假设说明**需求具体**（「看不见/看不懂/不会处理」高频出现）。
- 两者共同指向同一件事：**用户不缺「检测硬件」，缺的是「从数据到健康行动的翻译与决策层」**——这正是产品定位。

## 4. 调研产出如何落到产品

| 洞察 | 产品决策（对应交付物） |
|---|---|
| 「看不懂数字」 → 健康解读 | 健康画像 → 个性化方案引擎（`02-prd.md` §5.2） |
| 「不会处理」 → 决策支持 | 设备联动 + 分级预警（`02-prd.md` §5.3） |
| 隐私担忧 → 本地优先 | AES 加密 + 本地存储（`01-case-study.md` §4.3） |
| 付费意愿分化 → 分层 | 便携款（低门槛） + 旗舰款（全屋）双形态（`06-roadmap.md`） |
